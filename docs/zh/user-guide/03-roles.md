# 03 - 角色

> [English](../../en/user-guide/03-roles.md) | **中文**

> 读完这页你能：切换角色，并写出自己的角色。

## 角色是什么

角色就是一段系统提示词：`projv_files/prompts/` 下的一个 `.md` 文件，文件名就是
角色名。首次运行会生成四个：

| 角色 | 用来做什么 |
|------|-----------|
| `coder` | 默认。全套工具：读写改、shell、搜索、网页、todo、技能 |
| `designer` | 只读分析；写文件类工具被限制，用 `md_file` 输出设计文档 |
| `analyzer` | 代码分析，会调 `diagram_tool` 画图 |
| `compactor` | 内部用：上下文压力大时如何压缩早期对话 |

## 会话中切换

按 `Tab` 循环切换。上下文保留：切的只是系统提示词，不是对话内容。

## 写自己的角色

1. 新建 `projv_files/prompts/reviewer.md`。
2. 用普通 Markdown 写指令。要说清输出格式，也要说清「不要做什么」。
3. 按 `Tab`（或重启），`reviewer` 就出现在循环里了。

最小骨架：

```markdown
你是代码审查员。只报告，不改文件。

## 步骤
1. read_file 目标文件。
2. 以 `文件:行 - 严重度 - 问题` 的形式列出发现。
3. 最后给出最重要的一条修复建议。
```

## 角色管不到的东西

- **工具**是技能级配置，不是角色级。主 agent 始终拿到全套工具，角色提示词只能
  影响它「偏好」用什么。
- **角色配色**来自当前主题（`speaker_colors`），不是提示词文件。
